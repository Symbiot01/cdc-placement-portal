**Description** — paste all of this:

```
IIT Kharagpur students: this extension lets the CDC Placement Portal talk to official ERP from your own Chrome tab.

What it does
• Bridges the CDC Placement Portal to https://erp.iitkgp.ac.in
• Uses the ERP cookies already in your browser
• Loads placement roles, notices, and job descriptions
• Lets you apply or cancel with CV1, CV2, or CV3
• Blocks outbound requests to any host except erp.iitkgp.ac.in

What stays in your browser
• Roll number
• ERP password
• Security question answers
• Email OTP
• ERP session cookies

Those secrets are never sent to the placement portal backend. Login and apply traffic goes from this extension to ERP only.

How to use
1. Install this extension
2. Open the CDC Placement Portal
3. Click Set up login, fetch your 3 security questions, and save locally
4. Click Send OTP, enter the official ERP email OTP, then Open CDC
5. Browse roles and notices, open JDs, and apply or cancel from the portal

Optional Smart Apply
Smart Apply is off by default. If you later allow it in the portal, only resume PDFs, role rows, JDs, and notices may be sent for CV matching. Credentials and cookies still never leave Chrome.

Who this is for
Current IIT Kharagpur students who already have ERP access and use the CDC Placement Portal.

Not an official IIT Kharagpur, CDC, or ERP product. Unofficial student tool. Review permissions before installing.
```
